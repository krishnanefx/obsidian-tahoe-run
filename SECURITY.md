# Security policy

## Supported versions

Only the latest release of Tahoe Run gets fixes. Updating it in Obsidian (Settings → Community plugins) is how a fix reaches you.

## Reporting a vulnerability

Please report it privately with [Report a vulnerability](https://github.com/krishnanefx/obsidian-tahoe-run/security/advisories/new) under the repository's Security tab, not in a public issue. Only you and the maintainer can see it.

It helps to include:

- your Tahoe Run and Obsidian versions, and your device and OS,
- the steps that show the problem, or a small note or file that does,
- what someone could do with it.

The fix goes out in the next release, and the advisory is published with it. You're credited in the advisory unless you'd rather not be.

## What counts

Tahoe Run runs a note's code when you run it: that's what it's for, so code doing what it says isn't a vulnerability. It never starts running a note's code by itself. If you find a way to make it, for example by opening, previewing or syncing a note, that is one.
